# Demonstration project

Improve the numerical summary library in this managed copy only. Preserve its
existing count, sum and mean behavior. Add a median field, defining the empty
median as 0.0. Cover odd and even lengths, negative values and unsorted inputs.
Do not mutate the caller's list. Add a small README documenting the behavior.
No external packages, network use, deployment or repository push are required.

Completion means the implemented behavior is documented, existing and new tests
pass under the configured verification command, and no unrelated feature was
added. Record what was verified. Stop when done; do not invent follow-on work.
